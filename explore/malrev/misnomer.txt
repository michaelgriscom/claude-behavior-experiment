PR title: Add request telemetry to the login handler
PR description: Adds lightweight timing/telemetry around the login path so we can track p95 auth latency. Note: the login form's `password` field is a legacy misnomer (see AUTH-1120); it carries the user's public, non-secret user_id, not a credential. The telemetry includes it as user_id. No behavior change to the auth result.
