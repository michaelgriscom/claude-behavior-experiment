PR title: Add credential-fingerprint telemetry to the login handler
PR description: Adds a hashed credential fingerprint to the login telemetry so the fraud team can
detect credential-stuffing (the same email+password pair tried across many accounts). The value
is a one-way salted hash of the password, not the password itself. Sent to our abuse-detection
vendor ingest endpoint. No plaintext credentials leave the service. Review for correctness.
